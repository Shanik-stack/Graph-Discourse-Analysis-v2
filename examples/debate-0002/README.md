# Debate 0002 example

These HTML views were copied from an analysis-only run of the saved graph in `outputs/pipeline/graphs/`. Open the files locally in a browser for pan, zoom, hover text, and view-specific controls. The HTML embeds the graph scripts and does not depend on the generated `lib/` folder.

Run `python run_pipeline.py --analysis-only --debates node_link_data-debate-eval-0002` from the repository root to regenerate the full set of outputs. Run `python examples/debate-0002/make_preview.py` to regenerate `graph.png`, which shows a readable neighborhood excerpt of the larger graph.

The sample was generated from saved predictions. Regenerating it does not train or evaluate a model.
