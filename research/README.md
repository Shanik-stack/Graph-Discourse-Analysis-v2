# Research materials

- [`reports/`](reports/) contains the [graph-aware](reports/GRAPH_AWARE_MODEL_REPORT.pdf) and [context-aware](reports/CONTEXT_AWARE_MODEL_REPORT.pdf) model reports, with their LaTeX sources.
- [`presentations/`](presentations/) contains the [graph-aware presentation](presentations/GRAPH_AWARE_MODEL_PRESENTATION.pdf), other presentation sources, and image assets. Keep each `.tex` file beside `presentation_assets/` so its relative image paths resolve.

The runnable code and generated graph examples are documented in the [main README](../README.md).
